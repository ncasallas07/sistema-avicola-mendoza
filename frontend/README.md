# Frontend — Sistema Web Integral para la Gestión Comercial de una Distribuidora Avícola

Aplicación React (Vite + Tailwind CSS v4) que consume la API del backend de AVÍCOLA MENDOZA.

Ver el [README principal del proyecto](../README.md) para instrucciones completas de instalación, variables de entorno y ejecución.

## Scripts

```bash
npm run dev       # servidor de desarrollo
npm run build     # build de producción
npm run preview   # previsualizar el build de producción
npm run lint      # revisión de código con oxlint
```
